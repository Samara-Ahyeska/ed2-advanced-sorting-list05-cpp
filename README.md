## 🔍 Visão Geral

Este repositório contém os exercícios de fixação da disciplina de **Estruturas de Dados II (ED2)**. Os problemas abordam tópicos fundamentais sobre algoritmos de ordenação avançados (Merge Sort e Quick Sort), análise de complexidade, esquemas de particionamento (Lomuto vs. Hoare) e heurísticas para otimização e mitigação do pior caso.
